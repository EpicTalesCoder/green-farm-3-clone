# GLLib frame and animation exports

Generated by `tools/decode_image.py` from recovered Green Farm 3 resource packs,
using the local original JAR resource bytes. The JSON retains block-local module,
FModule, frame, bounds/rect, and animation-frame relationships. Numeric pack/block/
frame values are source identifiers; this export does **not** assign semantic
names such as Cindy Lou, wheat, tools, or a particular UI element.

Regenerate with:

```sh
for pack in 2 5 7 8 11; do
  python3 -I tools/decode_image.py \
    --pack "recovered/$pack" \
    --metadata-only --quiet \
    --summary "frames/pack$pack.json"
done
```

The format parsing is based on `decompiled-cfr/d.java`: modules are decoded before
frame composition; FModule records preserve the source module index, signed x/y
offset and flags; each frame preserves its FModule range and optional frame-rect
range; bounds and raw five-byte animation-frame records are retained. FModule
composition and transform semantics are implemented by the original renderer
around `d.java:1763-1855`. These records are an evidence foundation, not a
replacement for tracing object IDs from the world data and comparing scenes with
the original game.
